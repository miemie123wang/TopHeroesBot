TopHeroesBot11 header fix

Root cause confirmed:
- core/api.mjs used header key "Content-Type".
- signin.mjs added another key "content-type".
- Node fetch normalized and merged them into:
  content-type: application/json, application/json
- The new sign-in POST endpoint rejected that malformed media type with code 10003 Parameter exception.

Fix:
- Normalize all sign-in header names to lowercase before requests.
- Ensure exactly one content-type: application/json.
- Keep store.topheroes.com login, desktop UA, activity_id receive payload, and chain_id only for discovery/query.
